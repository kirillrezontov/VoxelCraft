## 4. REPLACE THE EXISTING FONT SYSTEM

The current UI uses a small built-in bitmap font rendered through mesh quads.

This is insufficient for a modern, scalable user interface.

Implement proper font rendering.

### Requirements

Support:

- TrueType/OpenType fonts.
- UTF-8 text input and rendering.
- Cyrillic characters.
- Latin characters.
- Numbers.
- Common punctuation.
- Adjustable font sizes.
- High-DPI displays.
- Multiple screen resolutions.
- Consistent text alignment.
- Text measurement.
- Text clipping.
- Efficient glyph caching.

Use a suitable established library, such as FreeType, or another justified solution.

A glyph atlas is recommended.

Use appropriate glyph rasterization and caching.

SDF/MSDF rendering may be considered if it offers practical benefits without introducing unnecessary complexity.

Do not rebuild glyph geometry every frame unnecessarily.

Bundle a redistributable font with a suitable license.

Suitable visual direction:

- Clean humanist or geometric sans-serif.
- Excellent readability.
- Slightly stylized to complement voxel graphics.
- Clear font weights and sizes.

Avoid tiny monospaced pixel text as the default for every UI element.

Preserve a monospaced font option for the developer console.

Document font licenses.

### Acceptance criteria

- Text looks crisp at common resolutions.
- UTF-8 strings render correctly.
- Cyrillic text is supported.
- Text measurements are accurate enough for layout.
- No major glyph atlas leaks or repeated expensive font loading.
- Existing game notifications remain readable.

- Numeric arguments.

- Player.
- Moderator.

- Server console.

6. Executes the command.
7. Returns a structured result.

Use the existing network protocol conventions.

Do not execute client-supplied code.

Do not trust client-supplied permissions.

Do not permit arbitrary filesystem or shell access.

Consider protocol version compatibility with v0.8.1 clients.

If protocol compatibility cannot be preserved, make the version mismatch explicit and reject incompatible connections cleanly.

# 42. OUT OF SCOPE

Do not implement the following as part of v0.8.2:

- Composite block cells.
- Multiblock structures.
- Arbitrary block geometry.
- New world dimensions.
- New biome generation.
- Major AI rewrites.
- Ray tracing.
- Full PBR rendering.
- Complete physics engine replacement.
- Large-scale networking redesign.
- Unrelated engine abstractions.

Keep the milestone focused.
