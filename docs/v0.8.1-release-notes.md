# VoxelCraft 0.8.1-rc1 — multiplayer stabilization

Release candidate; final platform acceptance is recorded in
[v0.8.1-stabilization.md](v0.8.1-stabilization.md). Not yet a stable release.

Implemented: per-profile private-server credentials; explicit trusted-LAN opt-in
for unauthenticated external binds; idle deadlines, server shutdown reasons and
protocol mismatch diagnostics; durable snapshot publication barriers; bounded
client chunk residency; terminal cleanup after malformed/truncated TCP frames; worker/save/render/network metrics; opaque greedy meshing
with repeated atlas tiles and unchanged transparent cube handling; single-frame
fence synchronization for mesh/HUD replacement; configurable window size,
fullscreen and VSync; sanitizer presets and separate client/server CPack archives.

World format 1, player payload versions 1..9, generator versions 1..3, namespaced
content and JSON/Lua API 1 remain compatible. Network protocol is now version 3:
upgrade client and server together. No automatic world migration is required.
Per-profile credentials are configured outside world snapshots.

The transport is plain TCP. Use trusted LANs or encrypted private tunnels only;
credentials do not provide encryption or protect against a network observer.
The server remains authoritative for movement, reach, inventory, mining, crafting,
combat and health. Lua has existing memory/instruction budgets and restricted
libraries; mods remain trusted local code, without a sandbox security guarantee.

Linux GCC/Clang builds, CPU/sanitizer tests and hardware Vulkan tests have passed
locally; separate Linux client/server archives pass extraction/runtime checks. MSVC builds
and Windows runtime checks must run through CI/the manual matrix before stable.
Performance results and exact test counts appear in the stabilization record.
Existing memory limits (8,192 saved chunks, 32 saved profiles, eight connected
players) remain; snapshot capture and full-world lighting can still cause stalls.
Palette storage is deferred to avoid changing the save format without measured need.
