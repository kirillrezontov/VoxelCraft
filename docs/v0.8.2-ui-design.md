# v0.8.2 UI and input design

The UI uses embedded DejaVu Sans and DejaVu Sans Mono, rasterized by the vendored
stb_truetype implementation. Both Latin and Cyrillic use strict UTF-8 decoding;
invalid input is rejected. DejaVu redistribution terms are included in
`assets/fonts/LICENSE-DejaVu.txt`; stb's MIT/public-domain alternatives are in
`third_party/stb/stb_truetype.h` and packaged notices. No font development package
or OS font installation is required. Only bundled trusted font bytes are parsed.

`engine/ui` owns font metrics, clipping, a bounded 2048² RGBA glyph atlas, UTF-8
text editing and the small CPU widget tree. Glyphs are keyed by face, scalar and
rounded pixel size; missing characters use a replacement glyph. The atlas holds
at most 8192 glyphs and preserves cached glyphs at saturation. Font loading occurs
once. The renderer uses a separate linear font sampler and preserves nearest
sampling for pixel art. Atlas uploads happen only when its revision changes, at
the existing frame fence. Text and colored backgrounds blend over the scene.

`SandboxUiController` owns the current screen, search/category/page, keyboard focus,
hover/tooltips, drag source, notifications and the console model. `SandboxUiLayout`
contains shared scale/layout rules. `sandbox_views.cpp` contains separate painters
for HUD, inventory, recipes, settings, pause, console and tooltips. Views read
state and emit mesh data; they do not craft, mutate worlds or issue network writes.
The widget tree supports panels, labels, images, slots, buttons, text fields and
scroll state without SDL or Vulkan. Keyboard traversal skips disabled widgets.

The default theme centralizes neutral backgrounds, square corner treatment,
borders, muted text, teal
selection and severity colors. The controller accepts programmatic theme overrides
without global style state. Layout scales from a 720-pixel reference height,
then constrains panels to the viewport. UI scale is 75–175%, persisted in settings
version 2; version 1 loads at 100%. Tests cover 320×240, 1280×720, 1920×1080 and
2560×1440 with minimum/default/maximum scale. Text clips to widget and viewport
bounds. Very small windows shrink the layout; use a larger window for comfortable
reading. Long identifiers/descriptions clip; full language localization, complex
script shaping and arbitrary font replacement are future work.

HUD geometry is retained until the screen, viewport, inventory, selection,
health or visible text changes. The console cursor updates twice per second.
Notifications retain at most eight messages, show three for four seconds and
fade for their final quarter second at a bounded update rate. Console output
retains 128 lines and only visible rows generate geometry. Command history holds
64 entries in memory and is never automatically written to disk.

## Controls

| Control | Action |
| --- | --- |
| E | Inventory; all registered items in creative, counted backpack in survival |
| C | Survival crafting; scroll changes recipe pages |
| 1–9 / mouse wheel in gameplay | Select hotbar slot |
| Creative click | Assign catalog item to selected hotbar slot |
| Creative right click hotbar | Clear assignment |
| Left drag survival slot to slot | Transfer/merge compatible stacks; swap incompatible stacks |
| Click backpack without dragging | Swap with selected hotbar (keyboard/click compatibility) |
| Right click backpack | Transfer rounded-up half to compatible selected hotbar slot |
| Right click hotbar / Shift click any slot | Quick transfer to the other inventory region |
| Tab / Shift Tab; arrows; Enter | Navigate and activate menu widgets |
| Click search | Focus UTF-8 search; names/identifiers/descriptions, Latin/Cyrillic case folding |
| F10 | Settings: FOV, sensitivity, invert Y and UI scale |
| Escape in gameplay | Pause menu: Resume, Settings, Save world |
| / | Console with slash inserted |
| T | Chat text; submitted as the shared `say` command |
| Grave physical key | Expanded developer console (layout independent binding) |
| Enter / Escape in console | Submit / return to the previous screen and capture state |
| Up / Down; Tab | History / registry-driven completion |
| Home/End, Shift arrows, Ctrl A/C/X/V | UTF-8 selection, editing and clipboard |
| Console wheel | Scroll bounded output history |

Inventory, crafting, settings, chat and console suspend gameplay input and release
relative mouse capture. SDL_TEXT_INPUT supplies characters; physical scancodes
only select actions/navigation. Solo Pause and Settings freeze movement, creatures,
mod ticks and the real day cycle. Inventory/crafting/console keep simulation running.
Multiplayer menus suspend local controls while the authoritative server continues.

Survival drag state stores only a source index. No counted items leave the actual
SurvivalInventory until its transaction commits. Closing a menu cancels the drag
without loss. Multiplayer sends the same bounded actions to the server and renders
its snapshots; there is no optimistic counted inventory. Creative assignments are
non-consuming item names, including tools and ordinary/modded items. Counted
inventory and durability survive mode switches. Crafting availability uses the
read-only eligibility API; the same transaction executes locally or on the server.
